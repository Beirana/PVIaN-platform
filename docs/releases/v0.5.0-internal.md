# PVIaN 0.5.0 正式内部版冻结说明

冻结日期：2026-07-31。

## 已冻结的消费者合同

下游仅配置网关 Base URL、独立 gateway client Bearer key 和 `/v1/models` 返回的 public alias。每个 alias
在 `config/public-model-aliases.json` 一对一绑定 profile、版本、endpoint、route 和 exact upstream model。
网关只在 alias facade 中重写顶层 `model`，并通过 `X-PVIAN-Public-Model`、`X-PVIAN-Route-ID` 与
`X-PVIAN-Alias-Facade` 响应头披露映射。其余请求字段和整个 HTTP/SSE response body 均保持透传。

所有消费者 API（`/v1/models`、诊断 route 与 chat completions）均要求 Bearer；只有 `/healthz` 和
`/readyz` 不鉴权。client key registry 不含真实密钥，运行时只保留 SHA-256 digest 并 constant-time 验证。
显式 `X-PVIAN-Route-ID + exact model` 路径仍可用于内部保真诊断，但不能绕过鉴权。

## 冻结验证

- 离线：Ruff、数据/OpenAPI/matrix/敏感字段与出站边界扫描、全量 pytest；
- 网关合同：missing/invalid/revoked key 的 401/403 和零上游、alias 唯一性/歧义、资格过期、profile
  version 漂移、route/model mismatch、gzip JSON、SSE `[DONE]`、reasoning/usage、tool/replay、429 与无 fallback；
- 状态并发：gateway 与外部 qualifier 的跨进程 success/failure/qualification 竞争、原子写失败后的恢复、
  以及无原始 provider 内容落盘；
- 消费者：普通 httpx 与 OpenAI Python SDK 通过 ASGI + MockTransport 测试 non-stream、SSE、thinking、
  native tool、assistant replay 与 tool-result replay。

最终离线回归为 **69 passed、1 条第三方 Starlette TestClient 弃用 warning**；Ruff、数据、OpenAPI、
Yunwu 4×3 matrix、敏感字段和未经授权出站扫描均通过，且全程设置 `PVI_NETWORK_DISABLED=1`。

发布前最小真实 smoke 还对当前 callable 的百炼 public alias 发起 1 次 non-stream thinking 请求：HTTP 200，
reported model、reasoning 字段、usage 与 route header 均通过。它是单一样本的当前时间窗观察，不构成 SLA。
完整的双审、修复与 smoke 摘要见 [`../reviews/v0.5.0-release-review.md`](../reviews/v0.5.0-release-review.md)。
测试不保存 provider key、原始 prompt/response/thinking 或远端错误正文。

## 部署与已知限制

- 只部署在本机/受控内网。内网 TLS/反向代理样例见
  [`../../deploy/nginx/pvian-gateway.conf.example`](../../deploy/nginx/pvian-gateway.conf.example)。
- provider key 继续仅在网关机器；不能复制到下游。外部 scheduler 在到期或五连败时才可显式运行资格复核；
  CI、启动和普通调用均不联网复核。
- qualification state JSON 与相邻 `.lock` 文件必须放在同一可写、支持跨进程文件锁的卷；当前不支持将
  它们放入无锁语义的多节点共享存储。
- 这不是 SLA、自动路由、自动 fallback、负载均衡、重试、费用系统、业务工具执行或验收 B Runtime。
- `misalignment-platform` 尚未被本提交修改；它应按
  [`../gateway-consumer-handoff.md`](../gateway-consumer-handoff.md) 实施独立薄客户端与验收。
