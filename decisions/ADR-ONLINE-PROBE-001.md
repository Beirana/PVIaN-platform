# ADR-ONLINE-PROBE-001：在线 Probe 采用显式授权的独立 Runner

- 状态：已接受
- 日期：2026-07-24
- 决策范围：验收 A 之外的受控可选扩展

## 背景

PVI-00 和原执行计划将在线 Probe、真实凭证和真实供应商请求排除在验收 A
之外。2026-07-24，操作方明确要求在不公开仓库、不改变核心服务默认行为的前提下，
增加面向 OpenAI-compatible 中转端点的联网验证能力。

## 决策

在线能力实现为 `pvi.probe_runner` 独立模块和 `pvi-probe` CLI：

1. 核心 FastAPI 服务不导入、初始化或调用在线 Runner；
2. SDK 是 `probe` 可选依赖，不进入核心运行依赖；
3. 每次真实请求同时需要 `--allow-network` 和 `--confirm-cost`；
4. `PVI_NETWORK_DISABLED=1` 的离线验收环境拥有最高优先级并拒绝联网；
5. 凭证只从供应商独立命名空间的环境变量读取；
6. 首期只发送合成文本、无副作用工具定义和合成流式请求；
7. 默认关闭 SDK 重试，避免一次 Probe 被隐式放大为多次计费调用；
8. 只保存脱敏元数据、摘要、延迟、usage 和模型标识，不保存原始提示、响应或凭证；
9. 结果输出为被 Git 忽略的候选证据，必须人工审核后才能进入 `data/`；
10. Probe 成功只证明该端点在该时间和配置下的观察结果，不证明上游模型身份。

## 后果

- 原验收 A、Docker 镜像和 GitHub CI 继续无凭证、无网络运行；
- 本机可以在明确授权下验证中转端点；
- 以后增加供应商时必须建立新的环境变量命名空间和主机白名单；
- 自动调度、能力自动晋升和 GitHub Actions 在线请求仍不实现。
